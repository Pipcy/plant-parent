# Plant Parent

Plant Parent is a SwiftUI iOS app for keeping a simple record of your plants and their care.

## Features

- Add, edit, and delete plants
- Record common and scientific plant species
- Save an optional plant photo and notes
- Capture progress photos with metadata-derived dates and optional notes
- Track how many days you have owned each plant
- Log watering, feeding, and repotting for today or a past date
- Review and delete care-history entries
- Store everything locally with SwiftData

## Requirements

- Xcode 15 or later
- iOS 17 or later
- XcodeGen (only needed to regenerate the Xcode project)

## Development

Open `PlantParent.xcodeproj` in Xcode, select an iOS simulator, and run the `PlantParent` scheme.

To regenerate the project:

```sh
xcodegen generate
```
